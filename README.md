# Task 2: Products Cards Page

## About the Project

This project is part of my **Webora Tec Frontend Development Internship Program**. It is a simple product cards webpage built using HTML and CSS, with a responsive navigation bar and a product-focused layout.

The page displays four product cards featuring product names, images, descriptions, prices, and Buy Now buttons. It was created as a practical exercise to improve my frontend development skills and demonstrate my understanding of webpage structure and styling.

## Features

- **Navigation Bar:** A navigation bar with Home, About, Services, and Contact links.
- **Hamburger Menu:** A menu button designed for mobile navigation.
- **Product Cards:** Four product cards displaying Apples, Oranges, Pineapples, and Grapes.
- **Product Images:** Individual images for each product.
- **Product Details:** Each card includes a product name, description, price, and Buy Now button.
- **Footer:** A footer displaying copyright information.
- **Separate CSS Files:** Stylesheets are organized into separate files for the navigation bar, product cards, and general page styling.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Make sure the `Assets` folder and its contents are present.
3. Open `index.html` in a web browser to view the webpage.

No additional frameworks or package installations are required for the basic HTML, CSS, and JavaScript implementation.

## Project Status

This is an internship practice project focused on frontend development. The Buy Now buttons and navigation links are currently part of the page's user interface and do not necessarily provide complete shopping or navigation functionality.
